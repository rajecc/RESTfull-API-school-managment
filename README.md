Проект RESTful API сервиса для управления школьными списками (**Классы**, **Учителя**, **Ученики**).

## Описание проекта

Разработка сервиса для автоматизации учета учебных классов, преподавательского состава и учеников с жесткой валидацией данных.

### Структура данных
*   **Класс:** `id` (int), `name` (str, до 20 симв.), `teacher_id` (int), `number_of_students` (int, от 0 до 40).
*   **Учитель:** `id` (int), `fio` (str, до 100 симв.), `class_id` (int).
*   **Ученик:** `id` (int), `fio` (str, до 100 симв.), `birth_date` (date), `class_ranking` (int).

## Эндпоинты

Для каждой из сущностей (`school_classes`, `teachers`, `students`) планируется реализация следующих методов:

*   `GET /api/...` — Получение списка всех объектов (`200 OK`)
*   `GET /api/.../:id` — Получение информации об объекте по ID (`200 OK` / `404 Not Found`)
*   `POST /api/...` — Добавление новой записи (`200 OK`)
*   `PATCH /api/.../:id` — Изменение информации об объекте по ID (`200 OK` / `404 Not Found`)
*   `DELETE /api/.../:id` — Удаление записи по ID (`202 Accepted` / `404 Not Found` / `500 Internal Server Error`)
